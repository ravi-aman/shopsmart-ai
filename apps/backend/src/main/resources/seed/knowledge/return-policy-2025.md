# ShopSmart Return Policy

## Overview

Most items bought on ShopSmart can be returned within the return window for their category. The return window starts on the delivery date.

## Return Windows by Category

- Electronics, including laptops: 10 days from delivery.
- Fashion and footwear: 30 days from delivery.
- Home appliances: 10 days from delivery.
- Books: 14 days from delivery.
- Groceries: not returnable.

## Opened Products

Opened electronics can be returned within 10 days if undamaged.
